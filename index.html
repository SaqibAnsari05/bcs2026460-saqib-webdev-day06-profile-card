Learning notes

This panel has a fixed maximum height. Scroll inside it to read the full notes.

HTML: HTML gives a webpage its structure. Semantic elements such as header, nav, main, section and footer make the page easier to understand.

CSS: CSS controls the appearance and layout. Flexbox and Grid help arrange elements, while media queries adapt the layout to smaller screens.

Box model: Every element can be understood as content surrounded by padding, border and margin. The universal box-sizing rule makes sizing easier to manage.

Positioning: Static is the normal flow. Relative keeps an element in the flow but allows offsets. Absolute positions an element relative to a positioned ancestor. Sticky and fixed are useful for navigation and floating controls.

Overflow: Overflow controls what happens when content is larger than its container. Auto adds scrolling when needed; hidden clips extra content.

1. Content: The actual text, image or other content inside the element.

2. Padding: Space between the content and the border.

3. Border: The line surrounding the padding and content.

4. Margin: Space outside the border that separates elements.
